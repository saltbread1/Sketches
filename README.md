# Processing Sketches

Sketches created using [Processing](https://processing.org/).

## Libraries

- Processing 4.4.7

## Run

You can specify and execute sketch classes under the 'sketches' package.
```shell
./gradlew run --args <sketch-class-name>
```
For example:
```shell
./gradlew run --args S20250621a
```
